# Spotify Agile Project.
## What this project does:
  This projects main purpose is for a user to input a song and have an AI check the statistics and recommend a similar song so the user can find new things to listen to.
  The AI is trained on a csv file which contained multiple songs and their stats such as "Danceablility", "Liveliness", "Instrumentalness" and "Energy"
  The user can receive multiple songs at once and sort by most similar, least similar and also have a filter for the same genre.

## Features
  A Tkinter GUI that the user can interact with.
  An Autofill to inform the user of the songs in the dataset.
  A sorting for most similar and least similar.
  A filter for songs that have the same genre.
  A radial chart showing the similarities between the provided song and selected song.
